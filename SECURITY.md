# Security Policy

## Supported Versions

The following versions of Joblio currently receive security updates and patches:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The Joblio team takes security and user privacy seriously. If you discover a security vulnerability in Joblio, please report it privately:

1. **Email Maintainers**: Send details to `workfordevashishhaldar@gmail.com`.
2. **Include Details**:
   - Description of the vulnerability and attack vector.
   - Proof of concept, HTTP payload, or reproduction steps.
   - Component affected (Mobile client, Node.js API Gateway, FastAPI AI Engine, or Clerk Auth integration).
3. **Response Timeline**:
   - We will acknowledge receipt of your report within 24 hours.
   - We will provide an initial assessment and patch timeline within 48 hours.
   - We will credit the reporter upon releasing a verified fix.

Please refrain from disclosing vulnerabilities publicly until we have reviewed and published an official security patch.
